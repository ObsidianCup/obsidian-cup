# Bangla writing style notes

For the owner's manual translation (Nov 2026). Based on a small sample: Bangla Academy spelling rules as quoted by Dhaka Times, The Daily Star Bangla sports reporting and a Daily Star piece on Bangla Academy. No good public Bangla tournament rules or sign-up terms were found to compare with, so legal wording still needs the lawyer.

| Topic | What these sources do | Use on the site |
| --- | --- | --- |
| Register | Standard চলিত, not সাধু and not slang | Use চলিত everywhere, including legal pages |
| Spelling | Bangla Academy rules are the reference | Foreign and non-tatsama words take only ই and উ, as in ইদ, not ঈদ |
| Sports terms | Written in Bangla script (ক্রিকেট, লিগ) | ভলিবল, ফুটসাল, টুর্নামেন্ট, সিজন |
| Numbers and dates | Bangla numerals (২০ দল, ১৮ নভেম্বর) | Keep ২০২৬ style; the site already does this |
| Abbreviations | Bangla script, explained at first use (বিসিবি) | Avoid OVC and OFC; write the event name |
| Explaining a rule | State the rule, then what it means in practice, one point per paragraph | Same for rules and FAQ |
